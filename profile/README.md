# irl-commons

Open data for IRL streaming: streaming live from outside, on the move.

Small datasets that any app, site, guide or community can reuse: a glossary of words, short quick checks for when a stream breaks, a catalogue of apps, services and hardware, links to public guides, and the shared formats and protocols that tie them together. Each comes with a JSON Schema and a validator.

- **Repository:** [irl-commons/irl-commons](https://github.com/irl-commons/irl-commons)
- **Licence:** data under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) (reuse it with credit), code under MIT.
- **Status:** an early version, curated by hand and incomplete. Entries carry the date they were last checked.

## Help improve it

Found a mistake, a dead link or something missing? [Open an issue](https://github.com/irl-commons/irl-commons/issues) or a pull request. Please link a public source and write in your own words.

irl-commons is meant to be neutral: it lists projects without ranking them, and being listed doesn't mean anyone recommends it. It was started by the person behind [OpenStreamBox](https://github.com/openstreambox), whose site uses this data, but it belongs to no app or service.
