# IRL Commons

Open standards and open data for IRL streaming: streaming your real life away from the desk, at home, at a venue or on the move.

- **Open data:** [irl-commons](https://github.com/irl-commons/irl-commons), small datasets that any app, site, guide or community can reuse: a glossary, a catalogue of apps, services and hardware, links to public guides, and the shared formats and protocols that tie them together. Each comes with a JSON Schema and a validator. Data under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) (reuse it with credit), code under MIT.
- **Open standards, early drafts:** [stream-status](https://github.com/irl-commons/stream-status), one shape for "what's wrong with the stream, where, and is it still live", and [stream-session](https://github.com/irl-commons/stream-session), so every device in one live show agrees on which show it is and who decides right now. No app uses them yet; comments are welcome in their Discussions.
- **Sites:** [howtoirl.org](https://howtoirl.org) for streamers and the people who help them, and [irlcommons.org](https://irlcommons.org) for the initiative, the standards, the data and how to contribute.
- **Reference build:** [OpenStreamBox](https://github.com/openstreambox) is one project that builds on these: a reference backpack build, with its working forks.

## Help improve it

Found a mistake, a dead link or something missing? [Open an issue](https://github.com/irl-commons/irl-commons/issues) or a pull request. Please link a public source and write in your own words. No GitHub account? Write to hello@irlcommons.org.

IRL Commons is meant to be neutral: it lists projects without ranking them, and being listed doesn't mean anyone recommends it. It belongs to no app or service.
